AI Assistants, round 2

Pebble Audio · built from assistant-first with the owner's changes · iPhone 390 × 844 · synthetic data

Round 2 keeps assistant-first's shape, Link, Choose, and Connect with a card per assistant, and gives it the calm of settings-native and the Muse screens. Brand marks give way to neutral initials tiles, and nothing promotes the feature on Ask. The intro and the linked screen use Muse's pattern, a state card with its next step and a “What goes to …” block before the button that starts anything. Choose now asks which conversations sync: all of them, those from a dated start, or a rolling window of the last 7 to 365 days, each with counts the phone knows. The Mac tools open your server's setup page in Safari, which shows the command with a fresh access key. Unlinking deletes the text from the server and says so. Privacy follows the shared model: one stance, one row per place your data goes, who can read your archive, and commitments derived from what is on.

  • Settings shows “Not set up”, matching the Muse row right above it, rather than “Off”.
  • Where it goes lists what the phone sends. The assistants that read your server appear once, under Who can read your archive, and the stance counts both.
  • ChatGPT's labels (Plugins, Add, Add custom MCP server, OAuth, Create as a plugin) are quoted as ChatGPT shows them. Those are the only places MCP and OAuth appear.
  • “Access key” appears only on the server page, where the person copies the command.
  • The Codex command and Cursor's Add to Cursor link are illustrative. Check each tool's current setup, and its labels, before the server ships its setup pages.
  • Round-2 review fixes are listed in CHANGES.md, with the decisions that need Roger.
  • Small gray text uses Tokens.tertiary. Destructive text uses a darker red that passes AA on white.
