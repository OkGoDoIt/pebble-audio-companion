# Pebble Audio Companion

A third-party Android/iOS companion app that receives background microphone audio from a
Pebble-class watch running custom firmware, stores it durably, transcribes it, and runs
user-controlled AI processing.

The watch keeps working normally with the **unmodified official Core Devices Pebble app**;
this app is a separate, dedicated audio receiver. The firmware side lives on the
`audio-companion` branch of the local `PebbleOS` checkout (service
`src/fw/services/audio_companion/`, GATT service
`src/bluetooth-fw/nimble/audio_companion_service.c`).

## Layout

- `spec/audio-companion-protocol.md` — normative wire protocol (version 1).
- `spec/fixtures/` — golden binary fixtures consumed by firmware C tests and KMP tests.
  Generated by `tools/gen_fixtures.py`; never hand-edited.
- `tools/fixtures_to_c.py` — emits the C fixture header used by
  `PebbleOS/tests/fw/services/test_audio_companion_protocol.c`.
- `core/protocol` — wire parse/build + stream model (pure KMP, no BLE).
- `core/transport` — receiver session state machine (auth, checkpoints, reconnect).
- `core/storage` — segment frame logs, metadata, retention, corruption recovery.
- `core/transcription` — provider abstraction, 4-mode router, durable queue, Speex decode.
- `core/ai` — AI processing over durable transcripts (design: `docs/ai-processing-design.md`).
- `adapter/ble-android` — CDM association, GATT client, foreground service.
- `adapter/ble-ios` — Core Bluetooth central wrapper with state restoration.
- `app` — Compose Multiplatform UI (Android entry; iOS host shell still to be added).

## Build

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
./gradlew :core:protocol:jvmTest :core:transport:jvmTest :core:storage:jvmTest \
          :core:transcription:jvmTest :core:ai:jvmTest
./gradlew :app:assembleDebug
./gradlew :adapter:ble-ios:compileKotlinIosSimulatorArm64
```

## Protocol fixtures

```sh
python3 tools/gen_fixtures.py          # regenerate spec/fixtures
python3 tools/gen_fixtures.py --check  # CI verification
python3 tools/fixtures_to_c.py ../PebbleOS/tests/fw/services/audio_companion_fixtures.h
```

Fixture changes require a protocol version decision (see spec Section 9).
